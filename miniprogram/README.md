# 知股 · 原生微信小程序

无 npm 运行依赖的原生股票 AI 研究界面。使用真实 `wx.login`，不提供模拟登录、开发者登录接口或游客账户。底部包含“AI 研究”和“每日复盘”两个 Tab：前者保留原有手动研究，后者展示定时预测与真实行情核验的统计，不承诺未来准确率或收益。

## 微信开发者工具

1. 在微信公众平台注册/选择一个小程序，将当前目录导入微信开发者工具，类型选“小程序”，不使用云开发。
2. `project.config.json` 已配置真实 AppID `wxa88701e1af24f636`。开发者工具登录的微信账号需要具备该小程序的开发权限；切换其他小程序时同步修改前后端 AppID。
3. 后端配置相同的小程序 AppID 和对应 AppSecret。**AppSecret、Azure 密钥、上游令牌均只能放在后端，不能写入此目录或小程序包。**
4. `config.js` 的 `API_BASE_URL` 已配置为 `https://trading.japaneast.cloudapp.azure.com`。仅填写 API 根地址，不附加 `/api`；本地已有旧副本时需重新同步配置。
5. 基础库建议使用项目设置的 `3.7.12` 或更新稳定版本，需要 `wx.getRandomValues`。无需“构建 npm”。
6. 编译，阅读并勾选登录提示，点击微信登录。后端必须可访问微信登录服务及其 Azure/行情依赖。

### 生产与真机

- 在微信公众平台“开发管理 → 开发设置 → 服务器域名”中登记 API 的 **request 合法域名**，使用有效 HTTPS 证书，建议标准 443 端口。
- 管理员已于 2026-09-30 确认在微信后台填写当前 Azure 子域名；还需保持校验开启，通过实际小程序请求验证设置生效。HTTPS 可访问不代表满足平台的域名/ICP备案要求；如被拒绝，需使用满足要求的自有域名，并同步修改后端代理和 `config.js`，不能靠关闭校验发布。
- 本项目提交的 `project.config.json` 保持 `"urlCheck": true`。发布前确认开发者工具没有禁用域名/TLS/证书校验。
- 真机不能通过手机的 `127.0.0.1` 访问开发电脑；预览/体验版请使用配置好的 HTTPS 合法域名。
- 不需要浏览器 CORS 代理，也不应将后端管理接口或密钥暴露给小程序。
- 微信审核前，维护者应在公众平台完善隐私保护指引、真实的数据用途/保存周期/联系方式，并核实所提供投资信息服务的合规要求。当前登录提示不能代替正式隐私政策或平台审核。

### 仅开发者工具本地联调：SSH 转发

假设远程后端在服务器 `127.0.0.1:8000` 监听，在**运行微信开发者工具的电脑**上执行：

```sh
ssh -N -L 8000:127.0.0.1:8000 azureuser@YOUR_SERVER
```

保持 SSH 会话运行，本地 `config.js` 暂改为：

```js
API_BASE_URL: 'http://127.0.0.1:8000'
```

端口需与实际后端一致。在**本地开发者工具**的“详情 → 本地设置”临时勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。这仅用于本地联调，**不要关闭提交的项目 URL 校验，不要用于生产或真机**。`project.private.config.json` 已忽略，不要提交本地设置。仍需真实 AppID、真实 `wx.login` 和后端 AppSecret；隧道并不替代微信认证。

联调结束后恢复 `config.js` 的 HTTPS 地址，并关闭本地“不校验”选项。不要为了调试把后端监听地址直接暴露到公网。

## 行为约定

### 每日复盘 Tab

- 与“AI 研究”共享微信登录状态。未登录时引导切回研究页完成原有授权流程，
  不增加另一套登录逻辑；401、退出或更换账号时清空页面数据。
- 默认股票选择来自 `GET /api/daily`（NVDA、MSFT、AAPL），可输入其他美股代码
  查询已有记录。查询不会创建定时任务或发起模型分析，不扣手动研究额度。
- `GET /api/daily/{ticker}` 展示累计、近 20、近 60 个交易日指标。没有有效样本时
  显示“—”与提示，而真实 0% 命中率显示为 0.0%，两者不能混淆。
- 逐日对照显示预测/实际收盘价、误差、方向核验，并可展开盘前依据、风险、
  盘后反思及候选经验。经验列表展示适用条件、建议、来源日期、支持/反证和状态。
- 历史每页 5 条、经验每页 10 条，翻页替换页面内容而非无限追加，避免超过
  微信 `setData` 上限。指标窗口只切换统计范围，不过滤下方分页记录。
- 股票切换、隐藏或会话变化后，旧响应不能覆盖当前页面。返回前台和下拉刷新
  重新读取；不持续轮询，不运行新的 AI 预测。读取失败保留同股票的上次数据并标记未更新。
- 共享定时研究不包含其他用户的个人任务。所有模型文本仍使用可选择的 `<text>`，
  不渲染 HTML/Markdown。日期按美东交易日展示，时间戳转换为北京时间。

### 原有手动研究

- 登录：`wx.login → POST /api/auth/wechat {code}`，保存后端返回的不透明 `access_token` 和 `expires_at`；其他请求携带 `Authorization: Bearer …`。令牌只存本机微信存储，不在界面或日志中输出。
- 使用 `GET /api/me` 显示实际额度、北京时间额度日期、服务端 `analysis_date_max`。默认每日 3 次，每人最多 1 个活动任务，全局串行；这些限制必须由后端强制执行，前端禁用按钮仅用于体验。
- 新建时先生成并同步保存 UUIDv4 `request_id`，再 `POST /api/predictions`。断网、超时、5xx 或无法理解的成功响应保留原参数/编号，重启后仍可“重试原请求”。成功响应（200/202）才记录任务并清除待确认提交；明确 4xx（408/425/429 除外）允许新的提交。401 会清除当前会话并要求重新登录。
- 429 可能是原任务已经创建后的重试被限流，不能据此确认原提交失败。因此遇到 429 仍保留同一请求编号和参数，稍后点击“重试原请求”；即使额度或活动任务状态改变，也不会重新生成编号。
- 待确认请求不可改代码/日期，即使额度变成 0 或已有活动任务，也可原样重试以取回幂等结果。不要通过清空微信存储绕开提示另建请求。
- 任务创建即计次，任务失败仍计次；原 request ID 的幂等重试不重复计次。额度按 `Asia/Shanghai` 的每日零点重置，以后端为准。
- 最近列表最多显示 20 条。保存当前选中的任务编号，选择或重新进入时总是请求详情，不能把没有 `result` 的摘要当完整报告。
- 活动任务每 4 秒读取状态；页面隐藏/销毁后不再调度轮询，已发送请求可以完成。返回前台复用在途请求，避免重复轮询。读取失败仅显示读取异常，不把任务改成失败。
- 每个响应都会校验会话代次；注销/重新登录后的旧响应不能覆盖新用户页面，旧 401 也不能撤销新会话。后端必须按用户校验任务归属，客户端过滤不能替代权限控制。
- 退出调用 `DELETE /api/session`，服务器确认撤销后才清除本地会话。网络失败会明确保留当前登录；已失效凭证的 401 则直接清除。
- 本地登录记录读取/清理失败会在开发者工具控制台显示不含令牌或底层异常内容的固定警告；读取失败按未登录处理。服务端确认撤销后，即使本地删除失败也会结束当前会话，不会阻止退出；请检查微信存储空间。
- 报告只用可选择的 `<text>` 展示，Markdown/HTML 都当普通文本，不渲染 `rich-text` 或网页。未知评级展示“需人工复核”。
- 美股示例：`NVDA` / `AAPL` / `MSFT`；港股：`0700.HK`；A 股：`600519.SS` / `000001.SZ`。最终规范化、可支持代码和数据可用性以服务端为准。
- “分析日期”不是保证无未来信息泄漏的回测时间点。AI 输出存在不确定性，请核对原始资料。

```text
utils/client.js                  真实登录、鉴权、会话隔离、持久化请求
utils/model.js                   日期/股票输入检查、状态和报告文本映射
pages/index/index.*              登录、额度、提交、进展、报告和最近任务
pages/daily/daily.*              只读每日预测准确性、逐日对照和经验
utils/daily.js                  复盘响应校验、指标与经验展示映射
tests/run.js                    无外部依赖的自动化测试
```

## 验证

开发机具备 Node.js 18+ 后执行：

```sh
cd miniprogram   # 若已在本目录则省略
node tests/run.js
```

测试通过单元级微信 API 替身覆盖真实登录流程的调用契约、会话过期与 401、旧会话响应隔离、退出失败保留会话、安全存储警告、UUID/持久化、网络不确定提交 → 429 → 200 的同编号重试、4xx 处理、额度/活动任务阻止提交时的明确提示、服务端最大日期、任务详情读取、停止/恢复轮询及文本报告。测试替身仅在 `tests/` 中，不参与应用登录。

还需在真实微信开发者工具/手机手动验收：

1. 同意提示后微信登录；检查额度、真实行情成功/缺失两类研究。
2. 断开网络提交再恢复，点击“重试原请求”，确认只产生一个任务/扣一次额度。
3. 排队或运行中离开再返回，确认继续显示原任务和最终报告。
4. 查看历史报告、切换任务并下拉刷新；验证三个额度用尽后不可新建。
5. 断网退出应保留登录；联网退出后重新登录，不应闪现前一会话的记录。
6. 两个真实微信账号分别验证任务隔离；过期令牌应回到登录页。
7. 编译更新后检查底部两个 Tab。进入每日复盘，切换 NVDA/MSFT/AAPL；
   首轮定时预测尚未结算时，应显示“暂无已结算样本”而不是示例准确率。
8. 有真实数据后切换统计窗口、展开每日反思、翻阅经验；快速切换股票和断网刷新，
   确认不会错配股票或把失败显示成空数据。查看前后核对手动研究额度不变。

自动化测试不能替代微信 WXML/WXSS 编译、真机样式/交互测试、域名审核或真实微信凭证联调。
